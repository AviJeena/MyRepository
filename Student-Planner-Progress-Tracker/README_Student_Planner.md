# Student Planner & Progress Tracker

## Overview
Student Planner & Progress Tracker is a full-stack productivity platform designed for students to manage academic activities efficiently. The system helps users organize tasks, schedule study sessions, track progress, manage notes, receive exam reminders, and improve productivity using a Pomodoro timer.

## Features
- Dashboard Management
- Task Management
- Pomodoro Timer
- Notes Module
- Calendar Module
- Exam Reminder System
- Profile Management
- Settings & Customization
- Dark/Light Theme
- MongoDB Data Storage

## Technology Stack
### Frontend
- HTML5
- CSS3
- JavaScript
- Font Awesome

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Localhost)
